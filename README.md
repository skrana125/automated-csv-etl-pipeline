# Automated CSV ETL Pipeline

## Project Overview

This project implements a production-style ETL (Extract Transform Load) pipeline using Python and Pandas. The system reads raw CSV data, performs data cleaning and validation, generates reports, and exports processed data.

This project demonstrates practical Data Engineering concepts such as data cleaning, validation, logging, and automated reporting.

## Pipeline Architecture
